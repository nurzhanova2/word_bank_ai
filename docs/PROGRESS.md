# Прогресс Bank AI for Word

Обновлено: 11 августа 2026 года.

## Готово

- [x] Локальное приложение для Windows и установка Word Add-in через EXE.
- [x] Подключение к корпоративному LiteLLM и модели `Qwen/Qwen3.5-35B-A3B-FP8`.
- [x] Действия: переписать, сократить, формальный стиль и проверка грамматики.
- [x] Перевод на русский, казахский и английский с контролем сохранения чисел, дат, сумм и реквизитов.
- [x] Расширение короткого фрагмента без добавления новых фактов.
- [x] Изменение тона: нейтральный, вежливый, строгий и дипломатичный.
- [x] Предпросмотр «Было / Стало» и подсветка изменённых слов.
- [x] Кнопки «Применить» и «Отклонить»; обе очищают результат после завершения действия.
- [x] Компактный интерфейс быстрых действий для узкой панели Word.
- [x] Валидация API, повтор запроса при повреждении критических данных и отключение reasoning-текста модели.

## Проверки текущего релиза

- [x] TypeScript typecheck всех пакетов.
- [x] Автоматические тесты локального провайдера.
- [x] Проверка новых режимов через API установленного EXE на корпоративной Qwen.
- [ ] Визуальная приёмка новых карточек непосредственно в панели Word.

## Следующие улучшения

- [ ] Обработка всего документа и выбранных разделов, а не только текущего выделения.
- [ ] Пользовательские шаблоны промптов и корпоративный словарь терминов.
- [ ] История последних преобразований без сохранения содержимого документов.
- [ ] Централизованное развёртывание и управляемая конфигурация для пилотной группы.
