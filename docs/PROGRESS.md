# Прогресс Bank AI for Word

Обновлено: 12 августа 2026 года.

## Готово

- [x] Локальное приложение для Windows и установка Word Add-in через EXE.
- [x] Подключение к корпоративному LiteLLM и модели `Qwen/Qwen3.5-35B-A3B-FP8`.
- [x] Действия: переписать, сократить, формальный стиль и проверка грамматики.
- [x] Перевод на русский, казахский и английский с контролем сохранения чисел, дат, сумм и реквизитов.
- [x] Расширение короткого фрагмента без добавления новых фактов.
- [x] Изменение тона: нейтральный, вежливый, строгий и дипломатичный.
- [x] Краткое содержание выделенного текста с сохранением ключевых фактов, сроков и реквизитов; результат добавляется ниже как `РЕЗЮМЕ:` без замены оригинала.
- [x] Предпросмотр «Было / Стало» и подсветка изменённых слов.
- [x] Кнопки «Применить» и «Отклонить»; обе очищают результат после завершения действия.
- [x] Компактный интерфейс быстрых действий для узкой панели Word.
- [x] Встроенное окно настройки API-ключа, адреса LiteLLM и модели без VS Code.
- [x] Валидация API, повтор запроса при повреждении критических данных и отключение reasoning-текста модели.
- [x] Единый реестр действий с декларативными параметрами, `applyMode` и префиксом результата.
- [x] Разделение AI-слоя на actions, providers, services и validators.
- [x] Маскирование чисел, дат, email и URL до отправки в LLM с точным восстановлением после ответа.
- [x] TDD-набор для реестра, реквизитов, retry и orchestration pipeline.
- [x] Word Add-in разделён на API client, WordAdapter, diff, UI renderer и controller.
- [x] Desktop Host разделён на ConfigService, RuntimeManager, WordAddInInstaller и settings IPC.
- [x] Типизированные безопасные ошибки с HTTP-статусом, `retryable` и `operationId`.
- [x] Расширенное маскирование ФИО, организаций, ИИН/БИН, IBAN, БИК, счетов и телефонов до обращения к LLM.
- [x] Автоматический eval-набор качества с измеримыми проверками реквизитов, структуры и длины результата.
- [x] Сохранение стилей абзацев, заголовков и списков через OOXML при неизменной структуре результата.
- [x] Защита границ абзацев от удаления или объединения моделью с автоматическим retry.
- [x] Сохранение смешанного форматирования `w:r`: жирное первое слово больше не делает жирным весь результат.
- [x] Поддержка Word-разделителей `CR`, `LF`, `CRLF` и пустых абзацев при применении результата.

## Проверки текущего релиза

- [x] TypeScript typecheck всех пакетов.
- [x] 85 автоматических тестов Add-in, Desktop Host и локального runtime.
- [x] Версия `0.3.4` отображается в панели и `/health`; установщик завершает старый фоновый процесс перед обновлением.
- [x] Для перевода используются ASCII-маркеры реквизитов и три recovery-попытки; исправлен ложный отказ казахского перевода.
- [x] Каждый action-промпт вынесен в отдельный файл и собирается единым XML-конструктором.
- [x] Усилены контракты `grammar`, `translate` и `summary`; для всех действий добавлено по два few-shot примера.
- [x] TDD-цикл новых этапов: сначала зафиксированы падающие тесты, затем реализованы и доведены до зелёного состояния.
- [x] Корпоративный трёхъязычный глоссарий подключается только к выбранному языку перевода.
- [x] Исходный документ передаётся как XML-кодированные недоверенные данные и не может закрыть системную оболочку `source`.
- [x] Каталог промтов версионируется отдельно от приложения; текущая версия — `2026.08.2`.
- [x] Eval проверяет обязательные термины и запрещённые служебные фразы; live-eval на корпоративной Qwen прошёл 6/6.
- [x] Единый `GrammarEngine` с позиционными ошибками, заменами, категориями, уверенностью и источником проверки.
- [x] Определение русского, казахского, английского и смешанного текста по предложениям с сохранением точных смещений.
- [x] Локальный LanguageTool для русского и английского; встроенный Java Runtime запускается скрыто вместе с приложением.
- [x] Казахская орфография проверяется локально через Hunspell (`myspell-kk`) с точными позициями и вариантами замены.
- [x] Добавлена первая версия казахских правил: повтор слова, пробел перед пунктуацией, смешение алфавитов и частые ошибки раскладки.
- [x] Ссылки, email, реквизиты, аббревиатуры и утверждённые банковские термины защищены от ложных срабатываний Hunspell.
- [x] Вкладка «Изменения» показывает точные диапазоны грамматических исправлений: удаление красным, замену зелёным, ручную проверку жёлтым.
- [x] Повтор одного слова исправляется удалением дубля вместо неудачной рекомендации LanguageTool поставить запятую.
- [x] Гибридная проверка объединяет LanguageTool/Hunspell с контекстным Qwen-review и сохраняет точные диапазоны каждого исправления.
- [x] Казахское банковское слово `Реквизиттер` добавлено в защищённый словарь; Hunspell-подсказки, разрывающие слово пробелом, отбрасываются.
- [x] Для всех преобразований вкладка «Изменения» показывает единый inline-diff без дублирования полных блоков «Было» и «Стало».
- [x] Блок `РЕЗЮМЕ:` получает через Word API вычисленный шрифт и размер последнего фрагмента, а также стиль, выравнивание, отступы и интервалы абзаца выделенного текста.
- [x] Новый адаптивный UI: сетка быстрых действий, отдельный тон, единый блок «Изменения» без вкладок «Было / Стало» и список грамматических ошибок.
- [x] Проверка новых режимов через API установленного EXE на корпоративной Qwen.
- [ ] Визуальная приёмка новых карточек непосредственно в панели Word.
