# Windows-пилот Bank AI

## Что устанавливается

`BankAI-Setup-0.1.4.exe` устанавливает приложение Bank AI for Word в профиль
текущего пользователя. Приложение работает в системном трее, запускает локальный
HTTPS runtime на `127.0.0.1:3847` и добавляется в автозапуск Windows.

## Установка

1. Закройте Microsoft Word.
2. Запустите `BankAI-Setup-0.1.4.exe`.
3. Если Windows SmartScreen покажет предупреждение, проверьте источник файла.
   Тестовая сборка пока не подписана коммерческим сертификатом.
4. Разрешите установку локального HTTPS-сертификата, если Windows запросит
   подтверждение.
5. Найдите зелёную иконку Bank AI в системном трее.
6. Откройте её контекстное меню и выберите **Открыть настройки**.
7. Вставьте API-ключ в появившемся окне и нажмите
   **Сохранить и подключить**. Адрес LiteLLM и модель уже заполнены.
8. Выберите **Установить дополнение в Word**.
9. После запуска Word откройте **Главная → Дополнения → Bank AI**.

Если автоматическая регистрация заблокирована корпоративными политиками,
выберите **Скопировать путь к manifest.xml** и передайте этот файл
IT-администратору для централизованной установки.

## Меню приложения

- **Статус** — состояние локального runtime;
- **AI** — активная модель или mock-режим;
- **Установить дополнение в Word** — регистрирует manifest и запускает Word;
- **Удалить дополнение из Word** — удаляет пользовательскую регистрацию manifest;
- **Открыть настройки** — открывает безопасную форму для API-ключа, адреса LiteLLM и модели;
- **Открыть диагностику** — показывает `/health`;
- **Скопировать путь к manifest.xml** — запасной путь ручной установки;
- **Перезапустить Bank AI** — перечитывает настройки;
- **Выход** — останавливает локальный runtime.

## Где хранятся настройки

Настройки находятся в пользовательском каталоге Electron `userData` в файле
`.env`, но пользователю не требуется открывать его вручную или устанавливать VS Code.
Окно **Открыть настройки** сохраняет параметры и автоматически перезапускает
локальный API. Ключ не хранится в manifest и не передаётся в frontend Word Add-in.

## Диагностика

При успешном запуске адрес должен вернуть JSON со статусом `ok`:

```text
https://localhost:3847/health
```

Если панель Word не открывается:

1. убедитесь, что Bank AI виден в системном трее;
2. проверьте диагностику;
3. полностью закройте и повторно откройте Word;
4. повторите **Установить дополнение в Word**;
5. проверьте, не блокируют ли Defender или корпоративные политики localhost,
   сертификат либо sideloading Office Add-ins.

## Получение `.exe` через GitHub Actions

Workflow `.github/workflows/build-windows.yml` собирает установщик на Windows.

1. Загрузите репозиторий на GitHub.
2. Откройте вкладку **Actions**.
3. Выберите **Build Windows installer**.
4. Нажмите **Run workflow**.
5. После завершения скачайте artifact `BankAI-Windows-x64`.
6. Внутри будет `BankAI-Setup-0.1.4.exe`.

При удалении приложения NSIS также удаляет регистрацию Bank AI из Word. Локальный
developer CA не удаляется автоматически, поскольку он может использоваться
другими Office Add-ins и его принудительное удаление может повредить их запуск.

Сборка предназначена для пилота. Перед распространением в организации установщик
нужно подписать сертификатом code signing и согласовать с IT/ИБ.
