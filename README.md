# Bank AI for Word

AI-помощник для редактирования выделенного текста непосредственно в Microsoft
Word. Пользователь выбирает фрагмент документа, применяет нужное действие,
проверяет предложенный вариант и самостоятельно решает, заменять ли исходный
текст.

## Возможности MVP

- работа в боковой панели Microsoft Word;
- получение текущего выделения через Office.js;
- семь действий над текстом:
  - **Переписать** — улучшить формулировки, сохранив смысл;
  - **Сократить** — убрать лишнее без потери ключевой информации;
  - **Формальный стиль** — привести текст к официально-деловому тону;
  - **Проверить грамматику** — исправить орфографию, грамматику и пунктуацию;
  - **Перевести** — переводить между русским, казахским и английским с сохранением реквизитов;
  - **Расширить текст** — подробнее раскрыть уже имеющиеся мысли без добавления новых фактов;
  - **Изменить тон** — выбрать нейтральный, вежливый, строгий или дипломатичный тон;
- предпросмотр результата в формате «Было / Стало»;
- применение результата к выделенному фрагменту кнопкой **Применить**;
- отклонение результата без изменения документа;
- понятные состояния загрузки и сообщения об ошибках;
- локальный backend, доступный только на компьютере пользователя;
- OpenAI-совместимый LiteLLM Chat Completions API и демонстрационный mock-режим без внешних запросов.

Ни одно изменение не применяется автоматически — финальное решение всегда
остаётся за пользователем.

## Как это работает

```text
Microsoft Word
   │
   │ выделенный текст
   ▼

   │
   │ HTTPS · localhost

   │
   ├── валидация запроса
   ├── выбор инструкции
   └── вызов AI Provider
          │
          ▼

```

## Требования

- Node.js 20 или новее;
- npm;
- Microsoft Word с поддержкой Office Add-ins;
- OpenAI API key для настоящей генерации;
- доверенный локальный HTTPS-сертификат.

## Установка

Установите зависимости:

```bash
npm install
```

Создайте локальную конфигурацию на основе примера:

```bash
cp .env.example .env
```

Заполните `.env`:

```dotenv
BANK_AI_PORT=3847
BANK_AI_PROVIDER=litellm
LLM_API_KEY=your_api_key
LLM_API_BASE=https://prod-litellm.nationalbank.kz
LLM_MODEL=Qwen/Qwen3.5-35B-A3B-FP8
```

Файл `.env` исключён из Git. Не добавляйте API-ключ в frontend, manifest или
исходный код.

В установленном Windows-приложении редактировать `.env` вручную не нужно:
откройте меню значка Bank AI в системном трее → **Открыть настройки**, введите
API-ключ и нажмите **Сохранить и подключить**. Приложение сохранит ключ только в
профиле текущего пользователя и перезапустит локальный API.

## Локальный HTTPS-сертификат

Office Add-in загружает панель по HTTPS. Перед первым запуском установите
сертификат разработчика:

```bash
npx office-addin-dev-certs install
```

Операционная система может запросить пароль администратора или подтверждение
доверия локальному центру сертификации.

## Запуск

Соберите проект:

```bash
npm run build
```

Запустите локальный runtime:

```bash
npm start
```

После запуска доступны:

```text
Панель:       https://localhost:3847
Healthcheck:  https://localhost:3847/health
```

Runtime слушает только `127.0.0.1` и не открывает API другим компьютерам в сети.

## Подключение к Word

Manifest дополнения находится здесь:

```text
packages/addin/manifest.xml
```

Загрузите его в Microsoft Word как тестовое дополнение. После подключения Bank AI
появится в списке дополнений Word и откроется в боковой панели.

Порядок sideloading зависит от платформы и настроек организации. На
корпоративных устройствах установка неизвестных дополнений или локальных
сертификатов может потребовать разрешения IT-администратора.

## Проверка без LLM API

Чтобы проверить интерфейс без API-ключа и передачи текста во внешний сервис,
измените провайдер в `.env`:

```dotenv
BANK_AI_PROVIDER=mock
```

Mock-провайдер возвращает демонстрационный ответ и позволяет пройти полный
сценарий «выделение → обработка → предпросмотр → применение».

## API MVP

### Проверка состояния

```http
GET /health
```

### Преобразование текста

```http
POST /api/v1/transform
Content-Type: application/json
```

```json
{
  "action": "formalize",
  "text": "Выделенный текст из документа"
}
```

Поддерживаемые значения `action`:

- `rewrite`;
- `shorten`;
- `formalize`;
- `grammar`;
- `translate` — требует `targetLanguage`: `ru`, `kk` или `en`;
- `expand`;
- `tone` — требует `targetTone`: `neutral`, `polite`, `strict` или `diplomatic`.

Текущий статус реализации и проверок ведётся в [docs/PROGRESS.md](docs/PROGRESS.md).

Максимальный размер текста в MVP — 20 000 символов.
